# 🎶🎥 Media Player App

A modern and feature-rich **Flutter-based Media Player** that supports both **video** and **audio playback**.  
Designed with **glassmorphic UI**, smooth **animations**, and multiple **themes**, the app provides a visually appealing and highly functional multimedia experience.

---

## ✨ Features

### 🎥 Video Player
- Supports **almost all video formats**
- **Playback controls**:
  - Play / Pause / Previous / Next
  - Skip 10 seconds forward or backward (button or gesture)
  - Picture-in-Picture (PiP) mode
  - Gesture controls: brightness, volume, and seek
- **Advanced options**:
  - Screenshot capture
  - Mute / Volume controls
  - Aspect ratio calibration
  - Rotate video
  - Mirror mode
  - VR mode
  - Audio-only mode (extract audio from video)
- **Content management**:
  - Add bookmarks
  - Add to favourites
  - Add to playlists
- **Playback customization**:
  - Playback mode (choose how the next video plays)
- **Extra tools**:
  - Share video
  - Trim video
  - Lock mode (prevent accidental touches)
  - Multiple audio track selection

---

### 🎶 Audio Player
- Supports **almost all audio formats**
- **Content management**:
  - Add to favourites
  - Add to playlists
- **Playback features**:
  - Background playback
  - Playback mode (how next track is selected)
  - Playback speed control
  - Waveform animations while audio plays
- **Enhancements**:
  - Equalizer with presets and detailed settings for audiophiles
  - Album art support
- **Extra tools**:
  - Set audio as ringtone
  - Share audio
  - In-app popup for "Now Playing"

---

### 📂 Media Library
- Automatically fetches and displays folders from the device containing:
  - **Videos**
  - **Audios**
- Playlists and favourites are available for **both video and audio**.

## 🖌️ Design
- **Glassmorphic design**
- Multiple **themes**
- Smooth **UI animations**
- Built with **MVVM architecture** ensuring scalability and clean code.
